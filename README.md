# Andrey Rukshenas — Portfolio

Personal portfolio website built with React, TypeScript, and Vite.

## Technologies

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React

## Getting Started

### Requirements

- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Check code

```bash
npm run lint
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
